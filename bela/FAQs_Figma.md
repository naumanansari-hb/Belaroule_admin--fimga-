# FAQs — Configuration Module (Figma Specification)

## Scope
Defines screens and behaviors for managing FAQs.

**Access:** Super Admin, Sub Admin (role-based)

---

## FAQ – Listing
- Search by Question
- Filter by Status

### Table Columns
- FAQ ID
- Question
- Status
- Created Date
- Action: Edit

## FAQ – Add / Edit

### Fields
- Question (mandatory)
- Answer (mandatory, rich text)
- Status (Active / Inactive)

### Actions
- Save
- Cancel
