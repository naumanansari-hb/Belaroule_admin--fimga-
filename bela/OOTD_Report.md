# Reports Module > OOTD Generation Report

## Scope
Read-only report for outfit generation activity.

Access: Super Admin, Sub Admin (role-based)

---

## OOTD Generation Report – Listing

### Filters
- Search by User Name
- Country
- Platform
- Date Range (mandatory)
  - Default: Current Month
- Apply

### Table Columns
- OOTD ID
- User (clickable)
- Date & Time
- Country
- Platform
- Default Outfit

### Pagination
- Server-side (10 / 25 / 50)

### Edge Cases
- No data → “No Data Available.”
