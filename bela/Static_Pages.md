# Static Pages — Configuration Module (Figma Specification)

## Scope
Defines screens and behaviors for managing static informational pages.

**Access:** Super Admin, Sub Admin (role-based)

---

## Static Pages – Listing
- Search by Page Title
- Filter by Status (Active / Inactive)

### Table Columns
- Page ID
- Page Title
- Slug / Identifier
- Status
- Last Updated Date
- Action: Edit

---

## Static Page – Detail / Edit

### Fields
- Page Title (mandatory)
- Slug (read-only)
- Content Editor (rich text)
- Status (Active / Inactive)

### Actions
- Save
- Cancel
