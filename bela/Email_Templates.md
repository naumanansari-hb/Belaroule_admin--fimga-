# Email Templates — Configuration Module (Figma Specification)

## Scope
Defines screens and behaviors for managing email templates.

**Access:** Super Admin only

---

## Email Templates – Listing
- Search by Template Name
- Filter by Status

### Table Columns
- Template ID
- Template Name
- Subject
- Status
- Last Updated Date
- Action: Edit

---

## Email Template – Detail / Edit

### Fields
- Template Name (read-only)
- Subject (editable)
- Email Body (rich text / HTML)
- Status (Active / Inactive)

### Actions
- Save
- Cancel
