# System Notifications — Configuration Module (Figma Specification)

## Scope
Defines screens and behaviors for managing system notifications.

**Access:** Super Admin, Sub Admin (role-based)

---

## System Notifications – Listing
- Search by Title
- Filter by Status

### Table Columns
- Notification ID
- Title
- Trigger Event
- Status
- Last Updated Date
- Action: Edit

---

## System Notification – Detail / Edit

### Fields
- Title (mandatory)
- Trigger Event (read-only)
- Notification Message
- Status (Active / Inactive)

### Actions
- Save
- Cancel
